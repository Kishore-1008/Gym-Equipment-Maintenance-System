# Gym Equipment Maintenance System

This repository contains the **User Authentication Module** of the Gym Equipment Maintenance System.

## Features

- User Login
- User Registration
- Role-Based Authentication (Admin, Technician, Staff)
- Responsive UI using Bootstrap 5
- Browser Local Storage for user data
- Form Validation

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap 5
- Font Awesome

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `login.html` in your web browser.

> You can also use the **Live Server** extension in Visual Studio Code for a better development experience.
